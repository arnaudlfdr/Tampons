# Atelier Tampons

Générateur de tampons en STL, à ouvrir dans le navigateur (Safari iPad compris) :
https://arnaudlfdr.github.io/tampons/

Tout est dans `index.html` (bibliothèques et polices intégrées). Le bouton télécharge un zip avec les STL de la plaque, de la poignée et une fiche d’impression.
